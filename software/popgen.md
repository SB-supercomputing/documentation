# popgen

Tools for population genetics analysis, including allele frequency and diversity.

The popgen module provides a collection of packages designed for population genetic and genomic analysis, enabling researchers to analyze genetic variation within populations.

**Module name** `popgen`

## Loading popgen

- module `popgen/1.0`

!!! tip ""
    **Tip:** load modules inside your SLURM job script, not just on the login node, so compute nodes see the same environment. Verify with `which` after loading.

## Example usage

**Load the popgen module**

```
module load popgen/1.0
```
