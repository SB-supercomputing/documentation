# GWAS

Tools for performing Genome-Wide Association Studies to identify genetic variants.

The GWAS module provides an environment for programs used in Genome-Wide Association Studies (GWAS), facilitating the identification of genetic variants associated with traits in large datasets.

**Module name:** `gwas`

## Loading GWAS

- module: `GWAS/1.0`

> [!TIP]
> Load modules inside your SLURM job script, not just on the login node, so compute nodes see the same environment. Verify with `which` after loading.

## Example usage

**Load GWAS**

```
module load GWAS/1.0
```

## Availability

GWAS is available on: SeaWulf, ClinWulf.

**Category:** Bioinformatics

**Applies to:** SeaWulf, ClinWulf
