# singlecell

Tools for analyzing single-cell RNA-seq and other single-cell omics datasets.

The singlecell module provides a conda environment with software specifically designed for working with single-cell RNA-Seq (scRNASeq) data, enabling high-resolution analysis of gene expression at the single-cell level.

**Module name** `singlecell`

## Loading singlecell

- module `singlecell/1.0`

!!! tip ""
    **Tip:** load modules inside your SLURM job script, not just on the login node, so compute nodes see the same environment. Verify with `which` after loading.

## Example usage

**Load the singlecell module**

```
module load singlecell/1.0
```
