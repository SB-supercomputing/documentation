# How do I request an Ookami account?

!!! note archive "Archived page"
    Ookami reached end of life at the end of 2025. This is a copy of its website, kept for reference; some original material is not included.

Currently, the Ookami cluster is primarily a testbed rather than a production environment and is best suited for software developers. Requests for production computing will receive lower priority access than testbed projects for the first two project years.

## Submitting Project Requests

To read about requirements for project requests, see **[How do I get a project on Ookami?](getting-a-project-on-ookami.md)**

## Requesting an Account

Account requests must go through [https://iacs.supportsystem.com](https://iacs.supportsystem.com/) and must have an accompanying Project number.

Account requests must be accompanied by a [Stony Brook NetID](https://it.stonybrook.edu/services/netid), which is required to access Stony Brook computing services. In the absence of a NetID, please submit a support ticket about requesting NetID credentials using the button below.

In case you got already a project number from your PI and want to be added as collaborator to an existing project, but don't have a SBU Net ID: Fill out this [form](../../files/support/faq/_docs/Volunteer%20Demographic%20Form%20-%20SBU.doc) and send it to "sarena dot romano at stonybrook dot edu". Then submit a [ticket](https://iacs.supportsystem.com/) including your NetID and project number to get your account.

[SUBMIT A TICKET](https://iacs.supportsystem.com/)
