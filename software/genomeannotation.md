# genome_annotation

Tools for annotating genomes with genes, regulatory elements, and other features.

The genome_annotation module provides various software tools essential for genome annotation tasks, including gene prediction, functional annotation, and sequence analysis.

**Module name** `genome_annotation`

## Loading genome_annotation

- module `genome_annotation/1.0`

!!! tip ""
    **Tip:** load modules inside your SLURM job script, not just on the login node, so compute nodes see the same environment. Verify with `which` after loading.

## Example usage

**Load genome_annotation**

```
module load genome_annotation/1.0
```
