# hts

A set of tools for working with high-throughput sequencing data.

The hts module provides an environment for software tools designed to process high-throughput sequencing (HTS) data, enabling efficient analysis of large sequencing datasets.

**Module name:** `hts`

## Loading hts

- module: `hts/1.0`

> [!TIP]
> Load modules inside your SLURM job script, not just on the login node, so compute nodes see the same environment. Verify with `which` after loading.

## Example usage

**Load the hts module**

```
module load hts/1.0
```
