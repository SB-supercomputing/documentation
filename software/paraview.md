# ParaView

An open-source data analysis and visualization application for scientific data.

ParaView is an open-source, multi-platform data analysis and visualization application. It is designed to visualize large data sets generated by scientific simulations, helping researchers gain insights into their models with advanced visualization tools.

**Module name** `paraview`

## Loading ParaView

- module `paraview/5.11.0`
- module `paraview/5.8.1`
- module `paraview/5.6.0`

!!! tip ""
    **Tip:** load modules inside your SLURM job script, not just on the login node, so compute nodes see the same environment. Verify with `which` after loading.

## Example usage

**Load the ParaView module**

```
module load paraview/5.11.0
```
