# Matplotlib

A Python plotting library for static, animated, and interactive visualizations.

**Module name** `matplotlib`

## Loading Matplotlib

Load the default module, or run `module avail matplotlib` to list every installed version on your cluster:

!!! note ""
    `module load matplotlib`

!!! tip ""
    **Tip:** load modules inside your SLURM job script, not just on the login node, so compute nodes see the same environment. Verify with `which` after loading.
