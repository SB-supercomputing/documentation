# metagenomics

Tools for analyzing metagenomic data to study microbial communities.

The metagenomics module provides a conda environment with a collection of packages specifically designed for working with metagenomic sequence data, enabling efficient analysis of microbial communities and their functions.

**Module name:** `metagenomics`

## Loading metagenomics

- module: `metagenomics/1.0`

> [!TIP]
> Load modules inside your SLURM job script, not just on the login node, so compute nodes see the same environment. Verify with `which` after loading.

## Example usage

**Load the metagenomics module**

```
module load metagenomics/1.0
```
