# Accessing the System

> **Status:** outline. Content arrives as Kitsune comes online.

> [!NOTE]
> **Cluster details.** <mark>Highlighted</mark> values are placeholders. Kitsune's queue names, module versions, paths, and addresses go in when the cluster is deployed.

You reach Kitsune two ways: a terminal over secure shell from Linux, macOS, or Windows, or Open OnDemand in a browser for everything graphical. Connect to <mark>Kitsune login address</mark> with the account and password from <mark>Kitsune account portal</mark>. Where multi-factor authentication applies, set it up before your first login.
