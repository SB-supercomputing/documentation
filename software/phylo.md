# phylo

Software for constructing and analyzing phylogenetic trees.

The phylo module provides software packages for performing phylogenetic analysis, enabling researchers to study the evolutionary relationships between species or genes.

**Module name** `phylo`

## Loading phylo

- module `phylo/1.0`

!!! tip ""
    **Tip:** load modules inside your SLURM job script, not just on the login node, so compute nodes see the same environment. Verify with `which` after loading.

## Example usage

**Load the phylo module**

```
module load phylo/1.0
```
