# Tutorials

Step-by-step lessons for Kitsune. Most take 10 or 15 minutes. The visualization lessons run their program in a browser session on a compute node, through [Open OnDemand](../reference/glossary.md#open-ondemand-ood).

> [!NOTE]
> **Cluster details.** <mark>Highlighted</mark> values are placeholders. Kitsune's queue names, module versions, paths, and addresses go in when the cluster is deployed.

## Before your first lesson

1. [Start an OnDemand session](visualization/start/ondemand-session.md). The visualization lessons all start from a session.
2. [Get your data where the app can see it](visualization/start/your-data.md), when you want to work on your own files. The lessons below use data that ships with each program, so you can skip this until you have files of your own.

## By program

Each program has a page listing its lessons by what they show. Start with the starter lesson, which covers opening a file, moving around it, coloring it, and saving a picture. The other lessons take one technique each.

| Program | Start with | Then |
|---|---|---|
| [ParaView](visualization/maps/paraview.md) | [Start ParaView on OnDemand](visualization/tools/paraview.md) | [Streamlines](visualization/vectors/streamlines/paraview.md), [orbitals and electron density](visualization/densities/orbitals-and-density/paraview.md) |

Lessons for ChimeraX, PyMOL, GaussView, IGV, MATLAB, JupyterLab, and RStudio are being written.
