# ParaView lessons

ParaView reads simulation output: flow fields, volumes, meshes, and time series. These lessons run ParaView on a compute node and show it in your browser. The batch-rendering lesson submits a job instead. Each takes 5 to 15 minutes.

> [!NOTE]
> **Cluster details.** <mark>Highlighted</mark> values are placeholders. Kitsune's queue names, module versions, paths, and addresses go in when the cluster is deployed.

## Start here

1. [Start an OnDemand session](../start/ondemand-session.md), if you haven't run one before.
2. [Start ParaView on OnDemand](../tools/paraview.md): opening a file, moving around it, coloring it, and saving a picture. It uses ParaView's own example data, so you need no files of your own.

To work on your own files instead, [get your data where the app can see it](../start/your-data.md) first.
