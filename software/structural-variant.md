# structural-variant

Tools for detecting and analyzing structural variations in genomes.

The structural-variant module provides bioinformatics tools designed for identifying structural variants in sequence data, allowing researchers to detect large-scale genetic variations, such as deletions, duplications, and inversions.

**Module name:** `structural-variant`

## Loading structural-variant

- module: `structural-variant/1.0`

> [!TIP]
> Load modules inside your SLURM job script, not just on the login node, so compute nodes see the same environment. Verify with `which` after loading.
