# Scikit-learn

A Python module for machine learning built on NumPy, SciPy, and matplotlib.

scikit-learn is one of the most popular open-source libraries for machine learning in Python. It provides simple and efficient tools for data mining and data analysis, including classification, regression, clustering, and dimensionality reduction. It is used in both academia and industry for building predictive models and analyzing data, and SeaWulf offers the latest version so users can integrate it into machine learning workflows with minimal setup and effort.

**Module name** `scikit-learn`

## Loading Scikit-learn

- module `scikit-learn/latest`

!!! tip ""
    **Tip:** load modules inside your SLURM job script, not just on the login node, so compute nodes see the same environment. Verify with `which` after loading.

## Example usage

**Load the scikit-learn module**

```
module load scikit-learn/latest
```
